# Licencias y Procedencia de Assets — El Lobo Jujeño

- **Código y geometría 3D:** 100% procedural en Three.js r128 (sin modelos `.glb` de terceros con licencias restrictivas).
- **Escudos y camisetas (`js/club_badges.js`, `js/player_renderer.js`):** Emblemas SVG originales estilizados de referencia cromática y texturas procedurales en `Canvas2D`. No se distribuyen escudos ni grabaciones protegidas oficiales.
- **Audio (`js/audio_engine.js`):** Síntesis 100% procedural vía Web Audio API sin archivos MP3/OGG externos.
- **Tipografías y librerías:** Three.js r128 (MIT), Tailwind CSS CDN y Google Fonts (`Barlow Condensed`, `Plus Jakarta Sans`, `JetBrains Mono`).
